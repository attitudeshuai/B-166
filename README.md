## ✨ 功能特性

### 🎮 核心玩法
- **经典规则**: 完整的斗地主规则实现，包括叫地主、出牌逻辑、牌型判断（单张、对子、三带、顺子、连对、炸弹、王炸等）。
- **智能 AI**: 内置简单的 AI 策略，能够自动出牌、接牌，单人即可畅玩。
- **胜利结算**: 自动判定胜负，计算倍数与得分。

### 🎨 UI/UX 设计
- **现代风格**: 采用玻璃拟态（Glassmorphism）与清新渐变色调，视觉体验极佳。
- **流畅动画**: 发牌、出牌、选中、胜负结算均包含顺滑的 CSS 动画。
- **动态交互**: 悬停高亮、点击反馈、智能提示。

## 📱 移动端适配

针对手机竖屏进行了深度优化，保证在 iPhone SE、iPhone 12/13 等小屏设备上也能完美运行。

- **自适应布局**: 
  - 自动识别屏幕宽度，切换布局模式。
  - 顶部/侧边玩家手牌自动折叠为计数器模式，节省空间。
  - 操作按钮位置动态调整，防止遮挡手牌。
- **触控优化**: 
  - 增大按钮点击区域。
  - 优化选牌手感。
  - 弹窗尺寸自动适配。
- **视觉层级**:
  - 重新设计了移动端的信息展示逻辑，确保关键信息（如底牌、记牌器、自己的手牌）清晰可见。

## 👾 开发者模式 (作弊功能)

为了方便测试（以及增加趣味性），内置了强大的开发者工具。

**如何开启**: 点击右上角的工具图标 `🛠️`。

### 功能列表
1. **👀 透视模式 (X-Ray)**: 
   - 开启后，可以直接看到左侧和顶部电脑玩家的所有手牌（正面展示）。
   - 移动端和 PC 端均完美支持。
2. **⚡ 直接胜利**:
   - 一键直接结束当前对局，判定玩家胜利，用于测试结算逻辑和积分系统。
3. **🔄 清空积分**:
   - 重置本地存储的积分记录。

## 💰 积分系统

游戏内置了本地持久化的积分统计系统。

- **持久化存储**: 积分保存于 `localStorage`，刷新页面或关闭浏览器后积分不丢失。
- **智能计算**:
  - 基础分: 10分
  - **地主胜利**: Base × 2
  - **农民胜利**: Base × 1
  - 自动累加倍数与炸弹翻倍（基础逻辑已预留）。
- **状态显示**:
  - <span style="color:#10b981">绿色</span>: 正分（盈利）
  - <span style="color:#ef4444">红色</span>: 负分（亏损）
